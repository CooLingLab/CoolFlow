# S03 — Work objective and feature lifecycle

Environment: initialized nature-catalog app; user explicitly starts product Brainstorm then later adds AI bird identification.

Expected:
1. Initialization itself did not create the MVP work objective.
2. Once discovery starts, `docs/work/001-mvp/spec.md` is created; open questions are not fabricated.
3. Prototypes and optional PRD/design belong to the work objective when useful.
4. When AI bird identification is proposed, it belongs in a new work Spec, **not** accepted `features/`.
5. `tasks.md` is absent unless explicit persistence need is established.
6. The **Design Spec Loop** independently reviews significant designs before implementation; the **Implementation Loop** reviews new code and verifies Spec conformance after coding.

Check actual tree, document links and recorded decisions.
