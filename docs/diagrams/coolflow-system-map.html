CoolFlow — AI Software Development System

One Development Flow · Three Adaptive Loops · Four Golden Rules — 面向个人开发者的 AI 辅助软件工程标准作业程序（推荐的八阶段主干可按需跳过、合并、重排或重访；包含双局部质量环、跨阶段演化环与文档契约）。

THREE ADAPTIVE LOOPS · 三个自适应循环

局部质量反馈与跨阶段产品演化严格分离

  • Design Spec Loop（阶段 06 蓝环）：Draft → 按需评审（可选 EGM）→ 修订 → 按需再评审，确保编码前 Spec 清晰自洽。
  • Implementation Loop（阶段 07 绿环）：Code → Test → Review → Spec Conformance；实现缺陷回 Fix，Spec 缺陷退回 06。
  • Evolution Loop（外围紫虚线环）：任意阶段的新证据或假设变化需要重估方向、范围或决策时可触发，重评后可重入任意相关阶段，绝非仅挂在 Release 后。

STAGE 08 & PRE-FLOW · 关键边界

验收 ≠ 发布，文档同步不是第四个循环

  • Human Acceptance ≠ Release：人工验收检验真实行为与测试证据；Release 在验收后遵循已有授权与发布安排。
  • Documentation Sync 是顺序步骤：验收通过后更新 docs/features/ 及受影响文档、归档证据，不属于第 4 个 Loop。
  • Project Initialization 为可选前置：非 Stage 00，不代表研发已启动，且不默认创建 solutions/ 或 adr/。

FOUR GOLDEN RULES & DOCS · 全局原则与产物

四条黄金法则与轻量化文档契约

  • Keep It Working → Ship Small → Improve：小步交付可用增量，持续演进。
  • Know the Actual State & Keep a Way Back：掌握真实系统状态，始终保留安全回退路径。
  • Prove It Works：以自动化/手工测试与审查证据支撑验收，按需沉淀 solutions/ 与 adr/。
