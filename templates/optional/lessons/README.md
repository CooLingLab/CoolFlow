# Project Lessons

This directory contains **verified, reusable lessons learned while building this project**. It is optional; create it only when there is a durable lesson worth retaining.

## How to use this directory

- Before work in an area with known lessons, read only the entries relevant to that area.
- Add a lesson only when evidence supports a finding that should change future decisions or actions.
- Keep one focused lesson per file and link to the source work item or verification evidence when available.
- Do not copy raw brainstorms, full debugging transcripts, unverified guesses, or every retrospective here.

## What belongs elsewhere

- Completed work evidence: \`docs/work/archive/\`
- Architecture decision rationale: \`docs/adr/\`
- High-priority instructions that Agents must always follow: \`AGENTS.md\`

Use the reusable [lesson template](https://github.com/CooLingLab/CoolFlow/blob/feat/v0.1-standard-and-init/templates/optional/lessons/lesson-template.md) when creating a new entry.
